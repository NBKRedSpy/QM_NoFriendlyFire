
Have you ever had a friendly AR Robot shoot you in the back at max rate of fire?

This mod turns off friendly fire for the player and their teammates.

[h1]Limitations[/h1]

This mod has the following limitations:
[list]
[*]The player can still cause friendly fire.  This is by design.
[*]Fire, explosions, acid, etc. are not blocked.
[*]While friendly fire will not cause damage, the floating damage text and combat log will still show the damage.
[*]Enemies can still cause friendly fire to each other.  This can be configured.
[/list]

[h1]Improvements[/h1]

This mod could be improved by not showing damage that has been mitigated.

[h1]Configuration[/h1]

The configuration file will be created on the first game run and can be found at [i]%AppData%\..\LocalLow\Magnum Scriptum Ltd\Quasimorph_ModConfigs\NoFriendlyFire\config.json[/i].
[table]
[tr]
[td]Name
[/td]
[td]Default
[/td]
[td]Description
[/td]
[/tr]
[tr]
[td]PreventEnemyFriendlyFire
[/td]
[td]false
[/td]
[td]When true, enemy factions will also have have friendly fire disabled.
[/td]
[/tr]
[tr]
[td]DebugLog
[/td]
[td]false
[/td]
[td]When true, adds logging information to the Player.log.
[/td]
[/tr]
[/table]
